导入后系统将优先使用您的 DAU、留存、收入等指标（覆盖 Mock）。Steam 口碑仍来自公开评论抓取。必填列：product、metric、值（或 value）。

路径 / 漏斗：若 CSV 含 installs、retention_1d/7d/30d，或指标名含「下载 / 注册 / 教程 / 战斗 / 付费」，看板「高级分析」中的漏斗将自动使用经营漏斗（非评论样本推导）。 仅有商店评论抓取时，无法还原「启动 → 登录 → 教程」等客户端埋点漏斗。详见 数据说明。

漏斗相关指标（可选）
