📖 API 文档

游戏数据分析引擎 REST API 参考文档

🔐 认证

POST /api/token

获取访问令牌

请求体

{ "username": "admin", "password": "admin123" }

响应

{ "access_token": "eyJhbGciOiJIUzI1NiIs...", "token_type": "bearer" }

📊 仪表盘

GET /api/dashboard

获取仪表盘数据概览

查询参数

参数 类型 说明
token * string 访问令牌
products string 产品ID列表，逗号分隔
time_period string 时间周期：today, yesterday, 7d, 30d

📄 报告

POST /api/report/generate

生成自定义报告

请求体

{ "report_type": "weekly_summary", "products": ["game_a", "game_b"], "date_range": { "start": "2024-01-01", "end": "2024-01-07" }, "metrics": ["抓取评论数", "样本好评率"] }
GET /api/report/{report_id}

获取报告详情

POST /api/report/{report_id}/share

共享报告

⚠️ 告警

GET /api/alerts

获取告警规则列表

POST /api/alerts

创建告警规则

请求体

{ "name": "评论量异常告警", "product": "game_a", "metric": "抓取评论数", "operator": "gt", "threshold": 1500, "email": "alert@example.com", "enabled": true }
PUT /api/alerts/{alert_id}

更新告警规则

DELETE /api/alerts/{alert_id}

删除告警规则

👥 团队

GET /api/teams

获取用户所在的所有团队

POST /api/teams

创建新团队

请求体

{ "name": "游戏运营组", "description": "负责游戏日常运营分析" }
GET /api/teams/{team_id}/members

获取团队成员列表

POST /api/teams/{team_id}/members

添加团队成员

请求体

{ "username": "new_user", "role": "editor" }

📈 指标

GET /api/metrics

获取所有指标数据

响应示例

{ "success": true, "data": [ { "metric": "样本好评率", "value": 85.1, "product": "game_a", "timestamp": "2024-01-15T10:00:00Z" } ] }

🛠️ SDK 集成

Python SDK

pip install game-analytics-sdk import game_analytics as ga client = ga.Client(api_key='your_api_key') # 获取今日数据 data = client.dashboard.get(time_period='today') # 创建告警 alert = client.alerts.create( name='评论量告警', metric='抓取评论数', operator='gt', threshold=1500 )

JavaScript SDK

npm install game-analytics-sdk import { GameAnalytics } from 'game-analytics-sdk'; const client = new GameAnalytics({ apiKey: 'your_api_key' }); // 获取今日数据 const data = await client.dashboard.get({ timePeriod: 'today' }); // 获取漏斗分析 const funnel = await client.analytics.getFunnel({ product: 'game_a' });
